# EDUS 268 — Artificial Intelligence and Machine Learning in Education

**Fall 2026 | Virginia Commonwealth University**

This repository contains course materials and resources for **EDUS 268: Artificial Intelligence and Machine Learning in Education** at Virginia Commonwealth University.

The course provides a beginner-friendly introduction to artificial intelligence and machine learning in educational contexts. Students explore how AI works, how it is being used in education, and important issues related to responsible and critical use of AI.

No prior programming or AI experience is required.
